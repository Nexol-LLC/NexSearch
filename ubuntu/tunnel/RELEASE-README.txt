NexSearch 1.6.7 — подключение существующего офисного Ubuntu-хоста

Распакуйте ZIP. В терминале перейдите в папку OfficeTunnel и выполните:

sudo bash connect-office.sh

Комплект предназначен для уже установленного офисного хоста NexSearch.
Он автоматически проверяет подпись обновления и использует существующий
закрытый ключ сервера, чтобы расшифровать настройки туннеля локально.
Ни пароль, ни ключ SSH вводить в программу не нужно.
На другом сервере расшифровка не сработает. Сотрудникам этот архив не нужен.

В конце должно появиться public_office_connection_verified: true, enabled / active.
Шлюз: https://111.88.129.166. Без белого IP и проброса портов в офисе.
Устанавливается только nexsearch-tunnel-office. PostgreSQL, клиентские базы,
почтовые аккаунты и сама версия NexSearch этим скриптом не изменяются.

Программу хоста обновите штатным nexsearch-update.service. Затем обновите
программы сотрудников до 1.6.7 или установите полные комплекты из релиза.
В приложении сотрудника выберите «Через интернет» или «Автоматически».
Публичный профиль подключения уже включён в комплекты для офисного хоста.

Диагностика: sudo journalctl -u nexsearch-tunnel-office -n 30 --no-pager
Отключение внешнего доступа: sudo systemctl disable --now nexsearch-tunnel-office
