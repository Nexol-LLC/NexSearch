# NexSearch 1.6.3

- Почта группируется по адресу собеседника. Стрелка раскрывает загруженные входящие письма и ваши ответы из «Отправленных» в хронологическом порядке. Темы сохраняются, ответы отмечены и имеют отступ, новые письма поднимают переписку вверх. Одинаковые отображаемые имена у разных адресов не объединяются.
- «Входящие» закреплены вверху списка папок. Вложенные папки раскрываются стрелками; поддерживаются родительские разделы, которые нельзя выбрать для чтения. Состояние раскрытия сохраняется при фоновом обновлении.
- HTML показывает встроенные CID-изображения, растровые data URI и внешние PNG/JPEG/GIF/WebP. Внешние картинки загружает хост без cookies и почтовых учётных данных. Доступ к ним проверяется по владельцу письма; закрытые адреса, активные форматы, слишком большие файлы и небезопасные перенаправления блокируются. Ошибку отдельной картинки можно повторить, не закрывая письмо.
- Письма, сохранённые предыдущей версией с удалёнными изображениями, один раз перечитываются с почтового сервера. Если сервер недоступен, остаётся доступна сохранённая копия.
- Временный обрыв IMAP больше не считается ошибкой пароля. Чтение и синхронизация повторяют подключение; неверный пароль не вызывает бесконечные попытки. Подключения ограничены и выполняются последовательно для одного ящика. Ограничено суммарное ожидание TCP-подключения, освобождаются оборванные сокеты.
- Автосинхронизация сохраняет период 60 секунд и включает отправленные письма для отображения ответов. Отправка SMTP и сохранение отправленной копии не повторяются вслепую после сетевой ошибки.

Требуются обновлённые хост и приложение сотрудника. Схема 18 добавляет только сведения о связях писем; аккаунты, пароли, письма и клиентские базы сохраняются. Миграция совместима с ранее установленными привилегированными обновляющими службами.

Группы строятся по уже загруженной почте. Для старой переписки используется «Загрузить более ранние». Личная почта остаётся недоступной другим сотрудникам, руководителям и директору.
