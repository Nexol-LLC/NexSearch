# PackOnTruck — формат импорта грузовых мест (Excel/CSV)

Первая строка — заголовки (игнорируется). Порядок колонок фиксированный:

| # | Колонка        | Тип   | Обяз. | Описание                                            |
|---|----------------|-------|-------|------------------------------------------------------|
| 1 | Наименование   | текст | нет   | Название позиции                                     |
| 2 | Длина          | число | да    | мм                                                   |
| 3 | Ширина         | число | да    | мм                                                   |
| 4 | Высота         | число | да    | мм                                                   |
| 5 | Вес            | число | да    | кг за одно место                                     |
| 6 | Кол-во         | число | нет   | по умолчанию 1                                       |
| 7 | Ярусы          | число | нет   | 1 = не штабелируется, 2 = в 2 яруса, 3 = в 3… (деф. 1) |
| 8 | Поворот        | 1/0   | нет   | разрешён поворот на 90° (деф. 1)                     |
| 9 | Группа         | текст | нет   | заказчик/группа — места группы укладываются вместе   |

Пример CSV:

```csv
Наименование;Длина;Ширина;Высота;Вес;Кол-во;Ярусы;Поворот;Группа
Паллета EUR;1200;800;1500;500;20;2;1;Иванов
Станок;2200;1400;1800;1900;2;1;0;Петров
Коробки;600;400;400;20;50;5;1;Иванов
```

Поддерживаются .xlsx, .xls, .csv (данные берутся с первого листа).

Изменение v0.5.0: колонки «Штабель» и «МаксСверху» заменены единой колонкой
«Ярусы» (количество ярусов штабелирования этого места).
