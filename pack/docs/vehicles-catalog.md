# Каталог грузовых площадей PackOnTruck

Источник: docs/Gabarity_gruzovykh_mashin_i_avtopoezdov.pdf.
Назначение: выбор грузовой площади, отсутствующей во встроенных шаблонах приложения.

## Как пользоваться

1. Найди подходящий транспорт в каталоге.
2. В приложении выбери «Свой размер…» и введи размеры кузова в **мм** (в каталоге — метры: 3 м = 3000 мм) и грузоподъёмность в **кг** (1 т = 1000 кг).
3. Для автопоездов (кузов + прицеп) используй шаблон «Автосцепка» или запроси добавление секционного шаблона в models.js.

Примечания к данным источника:
- Для бортовых машин высота в таблицах — высота **борта** (0.3–1.0 м), а не грузового габарита; при перевозке с тентом уточняй высоту тента.
- Прочерк — данных в источнике нет.
- Некоторые значения источника противоречивы (например, объём Газели «12–18 м³» при габаритах 3×1.9×1.5 м ≈ 8.6 м³) — перенесены как есть, ориентируйся на Д×Ш×В.
