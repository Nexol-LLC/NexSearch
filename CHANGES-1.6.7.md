# NexSearch 1.6.7

- Общий канбан клиентов по умолчанию для руководителей: генеральный директор видит всех сотрудников, руководитель отдела — себя и логистов своего отдела. На карточке указан ответственный; можно выбрать конкретного сотрудника либо «Только мои клиенты». Доступ логиста остаётся личным. История взаимодействий и передача клиента открываются прямо с карточки.

- «Настройки → Обновления → Обновить и перезапустить»: скачать подписанный пакет с хоста, проверить его, закрыть приложение, установить и автоматически открыть его с прежней учётной записью.
- Фоновая проверка не закрывает работающую программу. При ошибке установки сохраняется прежняя версия, снимается автоматический повторный запуск и показывается ошибка; рабочая программа открывается снова.
- Полный Windows-комплект обновляет уже установленную старую копию после проверки подписанного кода, а не открывает её молча. Перед запуском полного комплекта нужно закрыть прежнюю программу.
- Сохранено подключение через офисный VPS без VPN, публичный профиль включён. Офисный туннель устанавливается один раз подписанным комплектом Office-Connect.
- Для офисного Ubuntu добавлена команда `sudo /opt/nexsearch/venv/bin/python /opt/nexsearch/current/ubuntu/tunnel/install-from-cache.py`: устанавливает проверенный комплект из кеша обновлятора, без ручного скачивания ZIP и нового ввода GitHub-токена.

При переходе со старого приложения кнопка проверки уже скачивает новый пакет с обновлённого хоста. В старой версии требуется один раз полностью закрыть программу и затем открыть её; новая кнопка перезапуска появится после установки 1.6.7. Если старый клиент находится дома и ещё не знает адрес VPS, используется полный комплект из релиза. Новая регистрация и очистка базы не нужны. Схема PostgreSQL 19 не меняется.
