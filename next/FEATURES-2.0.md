# Возможности в локальной сборке 2.0

## Где найти

- **Подбор клиентов** в группе «Работа»: рекомендации по доступным компаниям, сферам, регионам, маршрутам и загрузке. Здесь же — рабочие профили сотрудников, досье компании и предложение передачи ответственного.
- **Настройки → Моё пространство**: рабочие сферы, регионы, направления, предел клиентов и цвет выделения. Светлая/тёмная тема и плотность остаются в «Внешний вид».
- **Настройки → Моё пространство → Личные сервисы**: название и HTTP/HTTPS-ссылка. После добавления кнопка появляется в «Сервисах» только в личном пространстве этой учётной записи. Кнопка «+ Мой сервис» в самих «Сервисах» открывает компактную форму с названием и ссылкой, без перехода в настройки.
- **Карточка клиента → Передать клиента**: доступна руководителю отдела и генеральному директору. Передача подтверждается в форме, сервер проверяет доступ к сотруднику и версию карточки; история, контакты и открытые задачи сохраняются.
- **Подбор клиентов → Запланировать подбор**: поиск выполняется на хосте в выбранное время, даже при закрытом приложении сотрудника. В форму подставляются применимые сферы и первый регион рабочего профиля; направления используются при последующем сопоставлении ответственного.

## Как работает подбор

Расчёт в Rust использует только данные, которые сервер уже разрешил просматривать текущему пользователю. Факты о чужой почте не запрашиваются. Профиль сотрудника выводится из доступной клиентской базы; собственные предпочтения можно дополнить вручную. Если отрасль или направление неизвестны, они не придумываются.

Проверяются подтверждённый действующий статус и контрольное число ИНН. Отказы исключаются. Для сочетания «компания — сотрудник» рассчитывается совпадение сферы, региона и маршрута, затем учитывается число клиентов относительно лимита профиля. Баллы — критерий сортировки, а не вероятность сделки.

Есть небольшая модель по явным исходам «взят в работу / отказ». Она требует минимум восьми собственных исходов сотрудника с обоими результатами и различающимися признаками. Пока этих данных нет, применяется объяснимое правило и показывается причина отсутствия обучения. Прежние записи с явной меткой «ДЕМО ·» или «DEMO ·» сохраняются в базе, но исключены из рекомендаций, рабочего опыта и обучения; новые компании не генерируются вместо поиска.

## Сохранение и ограничения

Рабочий профиль и личные сервисы сохраняются на этом компьютере отдельно по идентичности хоста и UUID пользователя. Настройки другой учётной записи нельзя сохранить через команду интерфейса. Системный сеанс на Windows защищён DPAPI пользователя; пароль и токен в JavaScript не выдаются. Личные настройки пока не синхронизируются между разными компьютерами через сервер.

Локальная проверка использует прежний Python-хост с его существующей PostgreSQL и новый Rust + Tauri клиент. Это не завершённый перенос всего сервера на Rust и не опубликованный рабочий релиз 2.0. Офисный сервер и GitHub в этой проверке не обновлялись.
