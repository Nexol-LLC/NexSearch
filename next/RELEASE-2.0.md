# NexSearch 2.0.0

Приложение сотрудника работает на Rust и Tauri, сервер — на Rust с существующей PostgreSQL. Сохранены привычный интерфейс, клиентские базы, перевозчики, история, задачи, почта и погрузка. Добавлены личные темы и сервисы, рекомендации, общий обзор для руководства и сохранённые схемы погрузки.

## Обновление с 1.6.7

1. Хост получает подписанные пакеты из веток `host` и `employe` по прежнему расписанию — в 10:00 по Москве. Для запуска проверки сразу администратор может выполнить `sudo systemctl start nexsearch-update.service`.
2. Ubuntu сначала устанавливает совместимый пакет. Автоматический повтор переводит службу на Rust, сохраняет PostgreSQL, прежний TLS-сертификат и учётные записи. До переключения создаётся резервная копия. При провале проверки здоровья возвращается прежняя команда запуска. Активные поиски завершаются до переключения.
3. Сотрудник открывает «Настройки → Обновления», нажимает «Проверить сейчас», затем устанавливает подготовленное обновление с перезапуском. Повторная регистрация не требуется; защищённый вход переносится после подтверждения прежнего хоста.

В папках сотрудников не нужно удалять старую программу: установка заменяет нужные файлы на месте. На Mac прежний ярлык сохраняется и передаёт запуск нативному приложению. Системное хранилище macOS при первом переносе может запросить разрешение доступа к сохранённому входу.

## Файлы выпуска

- `employee-windows.zip` — подписанный комплект сотрудника Windows; после распаковки программа находится в папке `EmployeeWindows`, запуск `NexSearch.exe`.
- `employee-mac.zip` — подписанное универсальное приложение для Intel и Apple Silicon; предназначено также для обновления существующего Mac-комплекта.
- Варианты `-local` закреплены за тестовым хостом домашнего компьютера; офисным сотрудникам нужны обычные пакеты.
- `host-linux.zip` — подписанное обновление установленного Ubuntu-хоста, не образ системы и не чистая база.
- `host-office-connect.zip` — прежний защищённый комплект подключения офисного сервера к VPS.

## Проверки и границы

Перед публикацией выполняются тесты Rust, анализ Clippy, проверки интерфейса и погрузки, сборки Windows/Ubuntu/Intel Mac/Apple Silicon, объединение Mac-бинарников и тест настоящего перехода службы Ubuntu через исходный обновлятель 1.6.7. На отдельной PostgreSQL проверены роли, прежние сессии, Excel, четыре одновременных поиска и подписанный переход установщика.

Проверки не заменяют наблюдение за реальным почтовым провайдером и сотрудниками после выпуска. Административные средства обновления и резервного копирования Ubuntu сохраняют Python для совместимости и отката; основная серверная служба и приложение сотрудника выполняются на Rust. Внешние сайты сервисов требуют доступа к интернету. Офисный сервер обновится при получении пакетов; публикация сама по себе не означает, что он уже обновлён.
